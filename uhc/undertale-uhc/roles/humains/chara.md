# 🔪 Chara

{% hint style="info" %}
Description du rôle \
\
Chara fait partie du camp des [Humains](./).

Elle obtient la liste de tous les Humains.
{% endhint %}

{% hint style="success" %}
Capacité

\
Plus votre [LOVE](../../particularite/love.md) augmente, plus vous gagnerez de la Force.&#x20;

Vous gagnerez 1% de force supplémentaire à chaque kill ainsi que des cœurs \
en fonction de votre [LOVE](../../particularite/love.md).


{% endhint %}
