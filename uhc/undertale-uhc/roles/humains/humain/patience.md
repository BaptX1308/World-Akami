# 💙 Patience

{% hint style="info" %}
Description du rôle \
\
Patience fait partie du camp des [Humains](../).
{% endhint %}

{% hint style="warning" %}
Passif\
\
Vous possédez l’effet <mark style="color:green;">**Résistance 1**</mark> à moins de 15 blocs d'un autre Humain.
{% endhint %}

{% hint style="success" %}
Capacité <br>

\
Vous avez un pouvoir qui permet d'immobiliser tout le monde dans un rayon de 15 blocs pendant 15 secondes avec la commande _**/patience**_



Vous pouvez utilisez ce pouvoir toutes les 20 minutes.



Après ces 15 secondes, les joueurs immobilisés pourront de nou&#x76;_&#x65;_&#x61;u bouger.



Vous possédez l’effet **Résistance 1** à moins de 15 blocs d'un autre Humain.
{% endhint %}
