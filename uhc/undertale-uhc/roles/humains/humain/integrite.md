# 💙 Intégrité

{% hint style="info" %}
Description du rôle \
\
Intégrité fait partie du camp des [Humains](../).
{% endhint %}

{% hint style="success" %}
Capacité \
\
Vous avez la capacité de repousser les personnes autour de soi grâce à la commance _**/integrite**_.

* Si les joueurs repoussés touche le sol, ils seront bloqués un certain temps.
* Si les joueurs repoussés dans les airs, ils seront bloqués un certain temps en air puis tomberont.
* Si les joueurs repoussés se heurte contre un mur ou un obstacle, ils prendront des coeurs de dégats.



Cette compétence a un temps de recharge de 8 minutes.
{% endhint %}
