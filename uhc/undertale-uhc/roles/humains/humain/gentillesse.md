# 💚 Gentillesse

{% hint style="info" %}
Description du rôle \
\
Gentillesse fait partie du camp des [Humains](../).
{% endhint %}

{% hint style="success" %}
Capacité

\
Vous pouvez cuisiner des plats pour votre équipe, chaque plat donne des effets pendant un certain temps.<br>

Vous pouvez utiliser votre pouvoir avec la commande _**/kind**_ suivie du nom d'un joueur.

Cette commande vous permettra de choisir un plat à donner à la cible voulue.

\
Vous pourrez choisir entre :

Steak / Côtelette / Poulet / Soupe / Carotte dorée\
\
Chaque repas donne un effet différent.

Vous pouvez cuisiner une fois par épisode.



Liste des effets :\
Steak = Résistance 1 et NoFall pendant 20 minute\
Côtelette = Donne Speed 1 pendant 20 Minute\
Poulet = Donne Force 1 pendant 20 minute\
Soupe = Donne une régénération de 1 coeur tout les 30 seconde pendant 20 minute\
Carotte Dorée = Soigne de 5 coeur instantanément


{% endhint %}
