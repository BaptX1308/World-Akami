# 🧡 Bravoure

{% hint style="info" %}
Description du rôle \
\
Bravoure fait partie du camp des [Humains](../).
{% endhint %}

{% hint style="warning" %}
Passif \
\
Chaque fois que vous tuez une personne, vous gagnerez <mark style="color:blue;">Speed 1</mark> pendant 30 seconde.

Vous possédez l’effet <mark style="color:$danger;">Force 1</mark> permanent.
{% endhint %}

{% hint style="success" %}
Capacité <br>

Vous pouvez sacrifier des cœurs permanent pour en donner à un autre humain&#x20;avec la commande _**/Bra**_ suivie du pseudo du joueur&#x20;(3 coeurs permanent max).
{% endhint %}
