# 👑 Asgore

{% hint style="info" %}
Description du rôle <br>

Asgore fait partie du camp des [Monstres](./)\
\
Vous êtes le Rois des Monstres tout les joueurs de la partie vous connaisse à l'annonce des rôles&#x20;
{% endhint %}

{% hint style="warning" %}
Passif\
\
Vous possedez 4 coeur permanent en plus de résistance permanent&#x20;
{% endhint %}

{% hint style="success" %}
Capacité\
\
Avec la commande /asgore vous pouvez connaitre qu'elle joueur à récupérer une âmes Humaines&#x20;
{% endhint %}
