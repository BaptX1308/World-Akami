# 🦸‍♂️ Papyrus

{% hint style="info" %}
Description du rôle <br>

Papyrus fait partie du camp des [Monstres](./).

Vous connaissez Sans à l'annonce des rôles.
{% endhint %}

{% hint style="warning" %}
Passif\
\
Vous possédez 2 cœurs supplémentaires.
{% endhint %}

{% hint style="success" %}
Capacité\
\
Vous avez un _**os**_(item) qui permet d’infliger 1 cœur de dégâts à la personne ciblée&#x20;

(cooldown de 20 sec).
{% endhint %}
