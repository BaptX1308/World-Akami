# 👩‍🔬 Alphys

{% hint style="info" %}
Description du rôle <br>

Alphys fait partie du camp des [Monstres](./)
{% endhint %}

{% hint style="warning" %}
Passif\
\
Vous avez Faiblesse permanent \
\
Vous pouvez endurcir un Monstre au nom de Mettaton que vous seule connait à l'annonce des rôles \
\
Seule vous connaissez l'avancement des stades de Mettaton&#x20;
{% endhint %}

{% hint style="success" %}
Capacité\
\
Avec la commande /Alp vous pouvais connaitre les effets des joueurs autour de vous sur 30 block&#x20;
{% endhint %}
