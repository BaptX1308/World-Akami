# 🦴 Sans

{% hint style="info" %}
Description du rôle <br>

Sans fait partie du camp des [Monstres](./).

Vous connaissez Papyrus à l’annonce des rôles.
{% endhint %}

{% hint style="warning" %}
Passif\
\
Vous avez <mark style="color:$info;">weakness 1</mark> permanent

Si vous êtes le dernier monstre en vie gagne <mark style="color:$danger;">Force 1</mark>, <mark style="color:blue;">Speed 1</mark> et <mark style="color:green;">Résistance 1</mark> permanent&#x20;
{% endhint %}

{% hint style="success" %}
Capacité\
\
Vous possédez un os qui permet d'infligé 1 cœur à la personne viser (cooldown de 10 sec)



Vous possédez aussi un nether star qui a l'activation envoie un message dans le chat disant "Last Attack" et après 5 seconde fait une énorme explosion sur 30 blocks autour de toi qui fais tomber les gens à 1 coeur (une seule utilisation)
{% endhint %}
