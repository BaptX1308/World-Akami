# 🎲 Temmie

{% hint style="info" %}
Description du rôle\
\
Temmie fait partie du camp des [Monstres](./)
{% endhint %}

{% hint style="warning" %}
Passif <br>

Temmie reçoit des effets aléatoires toutes les 5 minutes. \
\
L'effet dure 5 minutes. \
\
Liste des effets : \
\
\- Lenteur\
\- Faiblesse \
\- JumpBoost\
\- Force \
\- Regeneration \
\- Speed \
\- Résistance \
\- 2 Coeur en plus \
\- Une information permettant de savoir combien d'Humains se trouve proche de lui &#x20;
{% endhint %}
