# 🐐 Asriel

{% hint style="info" %}
&#x20;                                                                  Description du rôle \
\
<mark style="color:$warning;">Asriel</mark> est une forme de [Flowey](./).

tout les humains vous connaissent y compris Frisk.&#x20;
{% endhint %}

{% hint style="warning" %}
&#x20;                                                                         Passif&#x20;



Vous possédez <mark style="color:$danger;">Force 1</mark>, <mark style="color:green;">Résistance 1</mark> et <mark style="color:blue;">Speed 1</mark> permanent.
{% endhint %}

{% hint style="success" %}
&#x20;                                                                         Capacité&#x20;



vous possédez une capacité _**Éclair**_(nether star) qui fera tomber des éclairs sur les personnes autour de vous à moins de 30 block.
{% endhint %}
